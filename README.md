## Mettre en ligne avec GitHub Pages
1. Créer un dépôt sur GitHub (ex. `portfolio`) et y envoyer tous ces fichiers.
2. Dans le dépôt : **Settings → Pages**.
3. Source : **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
4. Le site sera disponible à `https://TON-PSEUDO.github.io/portfolio/`.
